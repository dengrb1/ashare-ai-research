# A 股 AI 自动投研系统 v2.0.2

## 安全收尾版本

v2.0.2 是 v2.0.1 的安全与交付收尾版本，包含已合并的投研、缓存、运行时、账户保护和原生管理器改动。
本版本不新增数据库迁移。

## 安全更新

- Windows 原生看门狗不再以 `SYSTEM` 身份执行控制器，改为使用受限的 `AshareAIService` 本地账户。
- 看门狗控制器固定复制到运行目录，并在安装后收紧运行目录 ACL，减少低权限用户通过可改写脚本获得高权限执行的风险。
- 清理旧的混合开发分支和其中提交过的 `.secrets` 文件；曾经出现在 Git 历史中的拓扑控制令牌仍应在部署环境中立即轮换。
- 继续保持生产环境的显式 Host、HTTPS、Bearer/HttpOnly Cookie、CSRF 和模型网关白名单校验。

## 功能收尾

- 合并 GPT 聊天持久化压缩、历史 bundle 复用与 Agent fallback、共享 AI 缓存、行情刷新、Windows 运行时和管理员账户保护。
- Windows 原生管理器位于 `windows/native-control-center/`，Linux 原生管理器位于 `linux/native-control-center/`。
- Windows 和 Linux 原生管理器均明确属于**测试版本，可能不稳定**，不建议直接用于生产环境；默认部署路径仍建议使用 Docker Compose。

## 升级与验证

已部署 v2.0.1 的用户可直接重建服务：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

发布包中的 Windows/Linux 原生管理器也必须按测试版本对待。部署者应在升级前轮换历史中曾出现过的拓扑控制令牌，并确认生产 `.env` 不在 Git 工作区内。

系统仍仅用于研究、回测和模拟组合，不提供自动实盘下单，也不构成投资建议。
