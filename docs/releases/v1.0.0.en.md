# A-share AI Research System v1.0.0

Release date: July 20, 2026

v1.0.0 is the first public stable release of the project. It provides a complete post-market workflow for
A-share research, deterministic scoring, candidate filtering, paper portfolios, event-driven backtesting,
reports, and Web administration. The system does not connect to live-trading execution. All outputs are for
research, backtesting, and paper-trading purposes only.

## Highlights

- Strict point-in-time controls, immutable manifests, content hashes, and lineage to prevent future data from entering research or backtests.
- Structured fundamental, technical, and event/sentiment agents with versioned, reproducible deterministic composite scoring.
- A dynamic tradable universe, effective-dated A-share T+1/price-limit/suspension/lot-size/fee rules, portfolio constraints, and a drawdown circuit breaker.
- Event-driven backtesting with three benchmarks, capacity analysis, attribution, and reproducible artifacts.
- An authenticated WebGUI for quotes and charts, watchlists and holdings, research, reports, paper trade plans, and administration.
- AI stock chat, intraday profit-exit monitoring, and reviewable paper exit advice that never changes holdings or places orders automatically.
- Separate Web cookie sessions and mobile Bearer tokens, including refresh, revocation, ownership checks, and idempotent task submission.
- A low-memory serial worker, isolated subprocesses for heavy jobs, bounded SearXNG concurrency, and lazy module loading.
- Local Docker Compose deployment, GHCR images, and automated standalone CLI builds for Linux and Windows.

## Security and public-release readiness

- Web mutations retain HttpOnly sessions and double-submit CSRF protection; mobile clients use short-lived access tokens and rotating refresh tokens only.
- Production mode enforces trusted hosts, an HTTPS model-gateway allowlist, secure cookies, and non-default infrastructure passwords.
- API errors, logs, and OpenAPI examples do not echo credentials, authorization headers, internal paths, or stack traces.
- Before the public release, the full Git history was scanned for secrets and Python/npm dependencies and source code were audited. No known dependency vulnerabilities or medium/high-severity static-analysis findings were identified.
- Report vulnerabilities privately through GitHub Private Vulnerability Reporting. See [SECURITY.md](../../SECURITY.md).

## API and mobile clients

The public business contract is under `/api/v1`. v1.0.0 includes mobile token login, refresh and revocation,
the application bootstrap summary, idempotent research/backtest/Trade Plan submission, and research-run status
queries. See the [API documentation](../API.md) for the full contract, status codes, security requirements,
and compatibility policy.

## Deployment and upgrade

For a new deployment, copy the example environment files, set strong random passwords and encryption keys in
the untracked `.env`, and run:

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

When upgrading from an earlier checkout, back up the PostgreSQL, Redis, lake, and object volumes first. Then
check out v1.0.0, rebuild the containers, and run the migrations. The database should end at Alembic revision
`0012_api_idempotency_keys`. Do not delete or reinitialize existing data volumes.

## Known boundaries

- This release supports research, backtesting, and paper portfolios only; it does not support automated live trading.
- Full production research requires an authorized canonical data source that satisfies the PIT contract.
- At least 2 GB of memory is recommended for small hosts; the parallel-worker profile should not be enabled on 1.5 GB hosts.
- Research outputs are not investment advice and do not guarantee returns.
