# A 股 AI 自动投研系统 v2.1.1

## 发布内容

- 新增有序的模型供应商故障转移能力。主要供应商遇到限流、超时、网关故障或传输异常时，系统可以在未输出正文前切换到下一供应商；不可重试的请求不会无条件扩散。
- 新增模型目录适配器，可按模型名称查询上下文窗口、输出预留、推理能力、结构化输出能力和参考价格，并且只在请求期间保留目录数据。
- 新增模型供应商配置迁移 `0033_model_provider_fallback`，保存有序供应商配置的空列表默认值，并兼容已有数据库升级和降级。
- 修复空数据库直接初始化后缺少供应商字段的问题；修复结构化请求耗尽重试后丢失故障转移标记的问题。
- 补充限流、网关错误、超时、传输异常、不可重试请求、迁移生命周期和日报字段的回归测试。

## 兼容性与安全

- 本版本未修改 `/api/v1` 的破坏性契约，现有研究、回测和模拟组合数据可以继续使用。
- 供应商故障转移只在正文输出前执行，避免同一个请求产生重复正文；请求继续使用原有幂等键。
- 数据库迁移会自动执行，不需要手动修改 `alembic_version`，也不会删除已有数据卷。
- 模型密钥继续使用现有的后端加密配置路径；供应商配置不得写入明文密钥。

## 升级方式

Docker 部署执行：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

升级后可执行数据库迁移和只读诊断：

```powershell
$env:PYTHONPATH='src'; .\.venv\Scripts\python.exe -m ashare_ai.cli migrate
$env:PYTHONPATH='src'; .\.venv\Scripts\python.exe -m ashare_ai.cli doctor --skip-market
```

Windows 和 Linux 原生管理器仍属于测试版，安装前请核对发布资产的校验文件。
