# A 股 AI 自动投研系统 v2.1.0

## 发布内容

- 行情服务支持受控的服务端预热、全日期范围交易日历和价格感知的研究候选池，减少首屏等待并保持研究预算约束。
- 新增运行时内存回收与可选 Rust 技术指标 kernel；未安装原生扩展时会安全回退到 Python 参考实现。
- 研究任务、交易计划、存储读取和回测路径补充容量、精度、PIT 与可追溯性校验，并扩展相应回归测试。
- Docker、Web、Windows 和 Linux 构建均由同一标签工作流验证；GHCR 标签与源码版本一致。

## 原生版 Beta 安装包

- `AshareAI-Windows-Native-Beta-v2.1.0.exe` 是 Windows 原生管理器安装程序，包含运行控制界面与命令行入口。
- `AshareAI-Linux-Native-Beta-v2.1.0.tar.gz` 是 Linux 原生管理器便携安装包。解压后运行 `./install.sh`，也可直接使用包内 `app/linux/native-control-center/` 的 GUI 或控制器。
- 两个原生版均为 **Beta 测试版**，请勿用于生产环境。安装前应在目标主机准备 PostgreSQL、Redis 或 Valkey，以及 Python 3.11 或 3.12；安装器会在缺少依赖时停止并给出诊断。
- 每个安装包均附带同名 `.sha256` 校验文件。下载后先执行校验再安装。

## 升级

Docker 部署可直接重建服务，现有数据卷不会被删除：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

本版本未引入破坏性的 `/api/v1` 契约修改。Edge Gateway 继续处于 Docker x86_64 Alpha 验证阶段，未包含在原生 Beta 的支持范围内。
