# A 股 AI 自动投研系统 v2.0.3

## 迁移兼容 hotfix

v2.0.3 是 v2.0.2 的迁移兼容 hotfix。分支拆分后，部分已有本地数据库仍记录旧混合分支使用的
`0026_ai_cache_singleflight` 版本标识；本版本识别该历史头并幂等升级到当前 `0027` 头，避免 API
在启动迁移阶段循环重启。

## 其他说明

- v2.0.2 中的 Windows 看门狗权限修复、运行目录 ACL 和历史凭据收尾继续有效。
- Windows 和 Linux 原生管理器仍属于**测试版本，可能不稳定**，不建议直接用于生产环境。
- 若部署环境曾使用旧混合分支，请继续轮换历史中出现过的拓扑控制令牌。

## 升级

直接重建并启动服务：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

本 hotfix 不删除数据卷，不要求手工修改 `alembic_version`。
