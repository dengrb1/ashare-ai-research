# A 股 AI 自动投研系统 v1.0.0

发布日期：2026-07-20

v1.0.0 是本项目首个公开稳定版本，覆盖收盘后 A 股研究、确定性评分、候选过滤、模拟组合、
事件驱动回测、报告和 Web 管理界面的完整工作流。系统不连接自动实盘下单，所有输出仅用于研究、
回测和模拟盘。

## 主要能力

- 严格的 PIT 时点约束、不可变 Manifest、内容哈希和数据谱系，避免未来信息进入研究与回测。
- 基本面、技术面和事件/情绪结构化 Agent，以及版本化、可复现的确定性综合评分。
- 动态可交易池、A 股 T+1/涨跌停/停复牌/申报单位/费用规则、组合约束和最大回撤熔断。
- 事件驱动回测、三基准对比、容量与归因分析，以及可复现的回测产物。
- 认证 WebGUI、行情与 K 线、自选股与持仓、研究中心、报告、模拟交易方案和管理功能。
- AI 股票问答、盘中盈利退出监控和待确认的模拟退出建议，不自动修改持仓或执行订单。
- Web Cookie 会话与手机客户端 Bearer Token 分离；提供刷新、撤销、资源归属校验和幂等任务提交。
- 适配低内存主机的串行 Worker、重任务隔离子进程、受限 SearXNG 并发和按需模块加载。
- Docker Compose 本地部署、GHCR 镜像和 Linux/Windows 独立 CLI 自动构建。

## 安全与公开发布

- Web 写操作继续执行 HttpOnly 会话与双提交 CSRF；手机客户端只使用短期 access token 和轮换 refresh token。
- 生产环境强制可信主机、HTTPS 模型网关白名单、安全 Cookie 和非默认基础服务密码。
- API 错误响应、日志和 OpenAPI 示例不回显凭据、认证头、内部路径或异常栈。
- 公开前已完成完整 Git 历史密钥扫描、Python/npm 依赖审计和静态安全检查；未发现已知依赖漏洞或中高风险代码问题。
- 漏洞请通过 GitHub Private Vulnerability Reporting 私下提交，详见 [SECURITY.md](../../SECURITY.md)。

## API 与手机客户端

公开业务契约统一位于 `/api/v1`。v1.0.0 提供手机客户端登录、刷新和撤销令牌流程、启动摘要、
研究/回测/Trade Plan 幂等提交，以及研究运行状态查询。完整契约、状态码、安全要求和兼容性规则见
[API 文档](../API.md)。

## 部署与升级

全新部署请复制示例环境文件，在未跟踪的 `.env` 中设置强随机密码和加密密钥，然后执行：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

从早期检出版本升级时，请先备份 PostgreSQL、Redis、lake 与 object 数据卷，再拉取 v1.0.0，重新构建容器并运行迁移。
数据库应最终位于 Alembic revision `0012_api_idempotency_keys`。不要删除或重新初始化现有数据卷。

## 已知边界

- 本版本只支持研究、回测与模拟组合，不支持自动实盘交易。
- 完整生产研究需要由部署方提供获授权、满足 PIT 约束的 canonical 数据源。
- 小型主机建议至少 2 GB 内存；1.5 GB 主机不应启用并行 Worker 配置。
- 投研结果不构成投资建议，也不承诺收益。
