# A 股 AI 投研系统 v2.2.0

## 发布内容

- 锁定研究只读模式：永久禁用 QMT、自动交易和实盘执行配置，健康检查明确暴露 `RESEARCH_ONLY` 状态。
- 新增统一 Rust Gateway，作为模型请求代理层；不包含交易逻辑，并提供熔断、密钥池、请求转发和健康检查能力。
- 新增行情与新闻 Bridge：补充腾讯/新浪实时行情和东方财富新闻数据，并接入 FastAPI 健康检查与市场服务。
- 新增 Docker Compose 服务编排和生命周期脚本，统一管理 API、Worker、Gateway、行情 Bridge、新闻 Bridge、PostgreSQL 与 Redis-compatible 服务。
- 新增 Windows/Linux 原生运行管理器能力，包括启动、停止、重启、修复、诊断、日志、看门狗和系统托盘；Windows 安装器支持开机启动和单实例控制。
- 新增离线部署包及 Windows/Linux 安装脚本，提供镜像导入、依赖安装、SHA-256 校验和部署文档。
- 完善研究只读、Bridge 集成、健康检查、新闻特征和部署配置的回归测试与完成报告。
- 修复部署脚本中的命令注入风险，并更新 `nanoid` 依赖以修复安全公告对应的问题。

## 兼容性与安全

- 版本从 `v2.1.1` 升级到 `v2.2.0`，未修改 `/api/v1` 的破坏性契约；新增健康检查字段均提供安全默认值。
- 本版本明确将系统锁定为研究、回测和模拟组合用途，不提供自动实盘交易能力。已有研究、回测和模拟组合数据可以继续使用。
- AI 设置继续由后端加密、校验、探测和审计；API Key 不写入前端本地存储、日志或报告。
- 新增 Bridge 和 Gateway 默认绑定本机地址；部署到其他主机前应按文档配置网络边界和访问控制。

## 升级方式

Docker 部署执行：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```

升级后执行数据库迁移和只读诊断：

```powershell
$env:PYTHONPATH='src'; .\.venv\Scripts\python.exe -m ashare_ai.cli migrate
$env:PYTHONPATH='src'; .\.venv\Scripts\python.exe -m ashare_ai.cli doctor --skip-market
```

Windows 和 Linux 原生管理器仍属于 Beta/测试版，安装前请核对发布资产的 SHA-256 校验文件。
