# A 股 AI 自动投研系统 v2.0.1

## 重大跃迁的安全修正版

v2.0.1 是 v2 重大版本的推荐正式版本。它完整包含 v2.0.0 从单点投研能力迈向可持续运行、可观测、可配置研究工作台的全部升级，并在正式发布验收中进一步收紧前端依赖安全基线。

## 安全更新

- 移除存在已知安全公告的 `react-router-dom 7.11.0`。
- 将浏览器路由入口迁移到 `react-router 8.3.0` 的统一公共 API，并锁定修复版本。
- 使用 npm 官方安全审计端点复核生产依赖，结果为 0 个已知漏洞。
- 路由结构、登录与权限边界、页面 URL 和 `/api/v1` 公开业务契约均未改变。

## v2 重大升级摘要

- AI 问答新增持久化上下文、缓存、成本治理、联网检索与可观测性。
- 新增持仓监控、退出建议、风险通知和系统配置中心。
- 高负载行情与研究任务进一步隔离，Worker 状态、租约和资源治理更完整。
- 行情刷新与预取提速，新增 A 股开闭市状态和休市提示。
- 候选股行业名称贯通采集、存储、API、报告和前端。
- 默认策略升级到 `first_release.v3`，历史配置继续用于可复现回放。
- 数据库迁移前进到 Alembic `0022_candidate_industry_name`。

完整功能、数据迁移和兼容性说明见 [v2.0.0 重大版本说明](v2.0.0.zh-CN.md)。系统仍仅用于研究、回测和模拟组合，不提供自动实盘下单，也不构成投资建议。

## 升级

已部署 v2.0.0 的用户应直接升级到 v2.0.1。重新构建不会增加新的数据库迁移：

```powershell
docker compose -p ashare-ai-src -f compose.yaml up -d --build
docker compose -p ashare-ai-src -f compose.yaml ps
```
