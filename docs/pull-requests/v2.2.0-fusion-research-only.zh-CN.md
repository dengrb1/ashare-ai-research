# PR 草稿：发布 v2.2.0 研究只读融合版本

## 摘要

本 PR 将系统版本从 `v2.1.1` 升级为 `v2.2.0`，完成研究只读融合、统一服务编排、Bridge/Gateway 集成、原生管理器增强和离线部署交付。

## 主要变更

- **研究只读闭锁**
  - 永久锁定 `RESEARCH_ONLY` 执行模式。
  - 禁用 QMT 和自动交易配置，健康接口公开返回只读状态。
- **服务与数据管道**
  - 增加 Rust 模型 Gateway。
  - 增加行情 Bridge 和新闻 Bridge，并接入健康检查与特征管道。
  - 统一 `compose.yaml`、服务依赖、健康检查和资源限制。
- **原生运行与部署**
  - 增强 Windows/Linux 原生控制中心、看门狗、日志、诊断和托盘能力。
  - 增加 Windows 开机启动、快捷方式参数持久化和 GUI 单实例控制。
  - 增加离线安装脚本、依赖锁定、镜像导入和校验文件流程。
- **安全与测试**
  - 修复部署脚本命令注入风险。
  - 更新 `nanoid` 安全依赖。
  - 增加研究只读、Bridge、健康检查、新闻特征和部署配置测试。

## 兼容性说明

- `/api/v1` 保持向后兼容；健康响应仅新增字段，且使用安全默认值。
- 数据库迁移沿用现有 Alembic 流程，不删除已有数据卷。
- 本版本明确只支持研究、回测和模拟组合，不支持自动实盘交易。
- Gateway、行情 Bridge 和新闻 Bridge 默认仅监听本机地址，外部访问需显式配置。
